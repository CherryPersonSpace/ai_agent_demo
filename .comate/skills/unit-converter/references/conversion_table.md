# 常用单位换算公式表

## 1. 长度（Length）

| 换算关系 | 公式 |
|---------|------|
| 1 千米(km) = 1000 米(m) | km → m: ×1000 |
| 1 米(m) = 100 厘米(cm) | m → cm: ×100 |
| 1 厘米(cm) = 10 毫米(mm) | cm → mm: ×10 |
| 1 英里(mi) = 1.609344 千米(km) | mi → km: ×1.609344 |
| 1 码(yd) = 0.9144 米(m) | yd → m: ×0.9144 |
| 1 英尺(ft) = 0.3048 米(m) | ft → m: ×0.3048 |
| 1 英寸(in) = 2.54 厘米(cm) | in → cm: ×2.54 |
| 1 海里(nmi) = 1.852 千米(km) | nmi → km: ×1.852 |
| 1 里 = 500 米(m) | 里 → m: ×500 |
| 1 丈 = 3.3333 米(m) | 丈 → m: ×3.3333 |
| 1 尺 = 0.3333 米(m) | 尺 → m: ×0.3333 |

## 3. 温度（Temperature）

| 换算方向 | 公式 |
|---------|------|
| 摄氏(°C) → 华氏(°F) | °F = °C × 9/5 + 32 |
| 华氏(°F) → 摄氏(°C) | °C = (°F - 32) × 5/9 |
| 摄氏(°C) → 开尔文(K) | K = °C + 273.15 |
| 开尔文(K) → 摄氏(°C) | °C = K - 273.15 |
| 华氏(°F) → 开尔文(K) | K = (°F - 32) × 5/9 + 273.15 |
| 开尔文(K) → 华氏(°F) | °F = (K - 273.15) × 9/5 + 32 |
